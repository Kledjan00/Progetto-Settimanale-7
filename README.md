# SportsHub
App web per cercare squadre di calcio, basket e football americano e seguirne le partite, su telefono, tablet e computer.
- Ricerca immediata: parte mentre scrivi e mostra sempre l'ultima ricerca.
- Scheda squadra: logo, campionato, prossime partite e ultimi risultati.
- Preferiti: si salvano con un clic e restano anche chiudendo la pagina.
- Agenda: le prossime partite di tutti i preferiti, in ordine di data.
- Filtro per sport: calcio, basket o football, su ricerca, preferiti e agenda.
- Scheda partita: loghi, punteggio, data, ora italiana, campionato, stadio.
- Modalità scura.
